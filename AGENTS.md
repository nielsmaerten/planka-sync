Development notes for agents working on this repository. (Not to be confused with the
`AGENTS.md` that planka-sync generates inside a mirror directory; that one comes from

## Issue and release workflow

Use [.agents/skills/planka-issue-workflow/SKILL.md](.agents/skills/planka-issue-workflow/SKILL.md)
when implementing an issue or cutting a release. Wait after Codex approval unless merging was
explicitly authorized; requested release metadata may go directly on `main` without another PR.
